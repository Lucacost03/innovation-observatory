# Innovation Observatory

Interactive agent-based economic simulator, engine 1.30.0, published with GitHub Pages.

The model and empirical inputs are copied from the verified published version 42 (source commit `73eda1b518c677f9eec6d1826bd84e313e211b8f`). The hosting migration does not change the simulation.

The first deployment retrieves the verified source archive and checks SHA256 `7f27eb8de94e035c53c63732bbe6e34a49b20f8be400265276242ddfcc0f4b68`. After a successful deployment, that archive is preserved in this repository so later deployments are independent of the original host.

GitHub Actions restores the losslessly compressed fixtures, runs the tariff/fiscal and inference checks, and publishes only the static website. Browser-local personal experiment settings are not part of this repository.

Accounting and software checks do not establish macroeconomic forecasting accuracy. The website includes source definitions, assumptions, executed comparisons and remaining model limitations.
